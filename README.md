#Course Page
This project is a portfolio-style Course Page designed to showcase a course catalog, featuring a secure login page with password restrictions to enhance user authentication. Developed using HTML, CSS, and JavaScript, the project aims to provide a seamless, secure, and visually appealing user experience.

1)Overview
The Course Page project serves as a professional portfolio showcasing an interactive, modern design for course listings. The page is equipped with a secure login functionality, ensuring that only authorized users can access certain course-related content. The core features of the project include:

A course catalog page displaying course information.
A login page with password restrictions for enhanced security.
A responsive design ensuring usability across devices.

2)Features
Secure Login Page: Users must authenticate using a username and password. The login page includes basic password strength checks to enforce security.
Course Catalog: The course page features a list of courses with basic information, such as course title, description, and instructor name.
Responsive Layout: The page adapts to various screen sizes, ensuring a great user experience on desktops, tablets, and mobile devices.
Interactive Elements: The use of JavaScript enhances user interaction, such as form validation and course filtering.

3)Technologies Used
HTML: For structuring the web pages and content.
CSS: For styling and making the pages visually appealing.
JavaScript: For interactive features like form validation, password restrictions, and dynamic content handling.

4)Usage
Open the login page where users can enter their credentials.
Passwords must meet specified strength requirements (e.g., minimum length, character diversity).
Upon successful login, users can view the course catalog and explore available courses.

5)Security Features
Password Restrictions: The login page enforces password security measures, requiring a mix of uppercase, lowercase, numeric, and special characters to ensure strong passwords.
Form Validation: JavaScript ensures that both the username and password fields are validated before submission.
